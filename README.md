**Electronic Health Record (EHR) Analysis & Modeling for predicting ICU length of stay (LOS) and Bias Nalaysis using Python**

This repository contains code, notebooks, and models for working with Electronic Health Records (EHR)-related data. It includes data processing scripts, machine learning models, and visualizations to explore and analyze healthcare records.

---

## 🚀 Overview

This project aims to provide a modular and reproducible framework for:

- preprocessing EHR data
- training and evaluating predictive models for LOS
- Bias analysis across demogrpahic  
- exploring results through plots and notebooks  

It is structured to support **research and development** workflows using Python and Jupyter notebooks.
